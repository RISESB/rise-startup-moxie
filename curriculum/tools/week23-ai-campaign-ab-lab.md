# AI Campaign Generator + A/B Lab (Week 23 tool)

Leave with a campaign you could run this week, two A/B versions to test one thing, and a plain-English way to read what the numbers tell you.

In class this is a one-page AI tool students open in their own Claude account. RISE Coach can run the same task right in the chat: ask for the inputs below, then follow the task.

## Ask the student for
- Who is this campaign for? - one specific segment, not "everyone" (e.g. parents of kids on my little brother's soccer team)
- What are you offering - and for how much? (e.g. custom team keychains, $8 each or 3 for $20)
- Where will it run? (choices: Instagram, TikTok, Email, Group text / iMessage, Flyer with a QR code, In person at a table/booth)
- What's the one action you want? (e.g. DM me to order)
- Anything that's worked (or flopped) before? - optional (e.g. what you've tried, your brand voice, anything true about these customers)

## The task
TASK: Help this student run one real marketing campaign and A/B test one thing in it. Return exactly these four sections with '### ' headers, nothing before or after:

### The campaign
3 short, ready-to-send pieces for the channel below — write the ACTUAL copy they can post, not a description. Match the channel's format (caption length, hooks, hashtags only where they belong). Each piece drives the one action.

### The A/B test
Pick ONE piece to test. State the single variable you're changing (e.g. the hook, the offer framing, the call to action) as a one-line hypothesis: 'If I change X, more people will Y, because Z.' Then write **Version A** and **Version B** — identical except that one variable.

### How to read the result
In plain language: what number tells them A or B won, roughly how many people they need to see it before the result means anything (warn against calling it on 5 clicks), and what to do next if it's basically a tie.

### One honest gut-check
The riskiest assumption baked into this campaign, and the smallest way to sanity-check it before spending real effort.
