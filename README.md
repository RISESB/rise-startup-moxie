# Requests

Request briefs that Startup Moxie students filed with RISE Coach for jobs too big for a chat: a website, a flyer, market research, a spreadsheet cleanup.

## How a request gets here

1. A student works out a brief with RISE Coach and asks to send it.
2. A RISE staff member approves it.
3. RISE's overnight run publishes the brief here, does the work, and emails the result to the student's RISE email.

Each file is one request. The header shows its status:

| Status | Meaning |
|---|---|
| `working` | Approved and picked up by the overnight run |
| `done` | Finished; the result was emailed to the student |
| `needs-human` | The run couldn't finish it safely or well; a staff member is following up |

## Privacy

This branch is public. Requests show a first name and last initial only. No email addresses, last names or contact details belong here, in the brief or anywhere else. Emails are looked up from a private roster when the result is sent.
